Это приложение для заучивания китайских слов. Оно позволяет выбирать категории слов и проходить тесты с четырьмя вариантами ответов. Проект создан как личный инструмент для изучения китайского языка, но код легко адаптировать под любые другие задачи (запоминание терминов, фактов, языков). Слова я беру в основном из китайских новелл, где есть магия и полёты на мечах, поэтому не удивляйтесь обилию специфических терминов.

Возможности: 

✅ Выбор категорий слов \
✅ Тесты с четырьмя вариантами ответов\
✅ Простая и понятная логика (легко расширить) 


Как это работает:

1)Запустите приложение. \
2)Выберите категорию слов (например, «Транспорт», «Дом», «Животные»).\
3)Нажмите «Выбрать».\
4)Выберите правильный ответ из четырёх вариантов.\
5)Получи результат и продолжайте тренироваться.
